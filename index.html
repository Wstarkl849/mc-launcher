📖 使用指南

🚀 启动游戏

① 选账号（外置登录填 LittleSkin）→ ② 选版本 → ③ 点「启动游戏」
第一次会下资源文件，等进度条走完

📦 加 Mod / 材质包 / 光影 / 数据包

① 左边点「Mod管理」→ ② 选对应标签页 → ③ 把文件拖进虚线框
Mod 用 .jar，材质包/光影/数据车用 .zip

🌐 在线下载 Mod

左边点「Mod仓库」→ 搜名字 → 选 Mod/整合包 → 点下载自动安装

🎮 装 Fabric（Mod 加载器）

选原版版本（如 1.20.1）→ 点「装Fabric」→ 装完选 fabric 版本启动

常见问题
• 游戏是英文？→ Options → Language → 中文（简体）
• 一直在下载？→ 第一次要下 3598 个资源，等它下完
• Mod 不生效？→ 确认选的是 fabric 版本启动
• 点 ❤️ 收藏的 Mod 会排最前面

⛏️ Minecraft 指令大全
💬 常用指令
/gamemode 0 生存模式 | /gamemode 1 创造模式
/gamemode 2 极限模式 | /gamemode 3 旁观模式
/give @s diamond 64 给玩家64个钻石
/tp @s x y z 传送到坐标
/tp @p @s 传送到最近的玩家
/time set day 设置白天 | /time set night 设置夜晚
/weather clear 晴天 | /weather rain 下雨
/heal @s 恢复满血 | /feed @s 恢复饱食度
/kill @e[type=!player] 杀死所有生物
/effect give @s speed 30 2 速度提升
🏠 服务器/管理
/op 玩家名 给管理员权限
/deop 玩家名 取消管理员
/kick 玩家名 踢出服务器
/ban 玩家名 封禁玩家
/pardon 玩家名 解封玩家
/whitelist on 开启白名单
/whitelist add 玩家名 添加白名单
/ban-ip IP地址 封禁IP
🧱 建筑/物品
/setblock x y z 方块名 放置方块
/fill x1 y1 z1 x2 y2 z2 方块名 填充区域
/clone x1 y1 z1 x2 y2 z2 x y z 复制建筑
/summon 实体名 x y z 生成实体
/setworldspawn 设置世界出生点
/gamerule keepInventory true 死亡不掉落
/gamerule doDaylightCycle false 锁定时间
🎯 其他实用
/xp add @s 100 给100经验
/enchant @s minecraft:sharpness 5 锋利V
/at +天名 私聊玩家
/spawnpoint @s 设置个人重生点
/worldborder 大小 1000 设置世界边界
/seed 查看种子
/locate village 寻找最近的村庄
